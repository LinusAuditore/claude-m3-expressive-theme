# M3 Expressive theme for Claude

A Material 3 Expressive look for the Claude desktop and mobile apps.

Soft rounded shapes float slowly around the edges of the window: cookies, clovers, flowers, pills, arches and rounded polygons, in classic red, yellow, blue and green. Now and then one gives a gentle spring bounce, and a few of them spring-morph into a different shape and back. The middle of the window, where the conversation sits, and the message box at the bottom are kept clear, and the panels are frosted so text stays easy to read.

- **Light mode:** white background with soft pastel shapes.
- **Dark mode:** deep space gray background with dimmer shapes.
- **Interface colors:** blue accents, red for errors, green for success and yellow for warnings.
- **Reduced motion:** if your system asks for reduced motion, the shapes stay still.

The theme draws in the Claude desktop and mobile apps only. The terminal and editor extensions don't draw themes.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install m3-expressive --marketplace LinusAuditore/claude-m3-expressive-theme
```

Answer `y` to add the marketplace, then choose the user scope so the theme loads in every session.

Or from a shell:

```bash
claude plugin install m3-expressive --marketplace LinusAuditore/claude-m3-expressive-theme
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `LinusAuditore/claude-m3-expressive-theme`, then **Add plugin**.

To turn it off later:

```bash
claude plugin disable m3-expressive@claude-m3-expressive-theme
```

## Customizing the shapes

The background is one SVG in `hooks/scene.ts`, generated by `tools/gen-scene.mjs`. Edit the shape list, colors or timings in the generator, then regenerate:

```bash
node tools/gen-scene.mjs hooks/scene.ts
```

The interface colors are set in `hooks/register.tsx`.
